Skills

The tools behind the desk. 75 skills that Claude Code loads when a task calls for one; 33 were built here and 42 come from other people.

A skill is a folder of instructions and scripts. Claude Code keeps a one-line description of every skill in view and loads the full instructions only when a task matches, so a long list costs almost nothing until it is used.

Most of the ones built here turn a job that came back every week into a fixed pipeline: the weekly account review, single-stock research, the barbell's daily reading, and the film formats used on social channels. 21 of the 33 were written in October 2026.

Each card below is one skill, or one group of skills that are used together, with a small sketch of what it produces. Open a card for how it is used and the runs on record.

What is not listed#

The stock skills that come with the Claude account (PDF, Word, slides, spreadsheets and similar) and two personal helpers are left out. Dates are when a skill first appeared on this machine. Updated November 1, 2026.
